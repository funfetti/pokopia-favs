# pokopia favorite items 

This is a simple tool to quickly view what items a Pokemon likes. (I was tired of having 12 tabs open and all the info scattered around.)

Favorites data is from [serebii](https://www.serebii.net/pokemonpokopia/) (and they're constantly updating so mine might be a lil out of sync at times). 
Logo is from from [pixelframe](https://pixelframe.design/pokopia-font-logo-generator/)
